# Security policy

This package is a research reference implementation and is not approved for production or safety-critical use.

Do not disclose suspected vulnerabilities in public issue trackers before coordinating with the author. No security contact address was supplied for this private package; contact must be agreed with the author through the repository's private collaboration channel before public release.

Reports should include the affected version, platform, reproduction steps, expected/observed behavior, and whether the issue crosses a stated trust boundary. Do not include personal data, production secrets, private keys or live exploit payloads.
